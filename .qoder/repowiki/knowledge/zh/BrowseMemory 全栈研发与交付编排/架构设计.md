- **统一依赖治理**：利用 `pnpm-workspace.yaml` 建立 Monorepo 结构，在根目录集中管理 TypeScript、React 及测试工具链，确保子模块环境一致性。
- **标准化工程链路**：通过根目录的 `package.json` 脚本统一驱动 `wxt`（扩展构建）与 `vitest`（单元测试），并配置全局 `tsconfig.json` 与 `eslint.config.js` 实施跨模块的代码规范约束。
- **差异化 CI/CD 编排**：在 `.github/workflows` 中定义双轨发布策略，`release.yml` 负责扩展的打包与 GitHub Release 分发，`pages.yml` 针对 `website` 目录变动触发静态站点的自动化部署。
