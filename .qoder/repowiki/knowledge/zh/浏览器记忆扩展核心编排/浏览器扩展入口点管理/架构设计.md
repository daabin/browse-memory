- **后台服务 (Background)**：作为核心控制器，初始化应用层 (`BrowseMemoryApplication`)、会话协调器 (`SessionCoordinator`) 及任务队列 (`TaskRunner`)，并注册浏览器事件监听（标签页切换、闹钟报警、运行时消息）。
- **内容脚本 (Content Script)**：注入网页，通过 `MutationObserver` 和历史 API 劫持监测页面导航与标题变化，向后台发送 `PAGE_CHANGED` 消息。
- **用户界面 (UI Entrypoints)**：包含 `dashboard`、`options`、`sidepanel` 三个独立 React 应用。各入口点通过 `main.tsx` 挂载根组件，并统一包裹 `I18nProvider` 实现国际化支持。
- **依赖方向**：入口点文件位于顶层，依赖 `src/` 下的业务逻辑、存储层及 UI 组件库，形成清晰的单向依赖结构。
