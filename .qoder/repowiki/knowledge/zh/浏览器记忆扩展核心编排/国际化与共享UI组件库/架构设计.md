- **i18n核心层**：`src/i18n/index.tsx` 基于 React Context 实现 `I18nProvider`，支持10种语言的动态切换、本地存储持久化及跨页面（storage事件）同步，并内置 RTL（从右至左）布局支持。
- **共享契约层**：`src/shared/` 定义了全局 TypeScript 接口（`types.ts`）、Runtime 消息通信协议（`messages.ts`）、应用默认配置（`constants.ts`）以及 URL 规范化与黑名单过滤策略（`url-policy.ts`）。
- **UI原子组件层**：`src/ui/` 封装了无头或轻量级 UI 原语，包括自定义 Markdown 解析器（`MarkdownContent.tsx`）、玻璃态容器（`GlassSurface.tsx`）及域名首字母图标（`DomainIcon.tsx`），通过 `utils.ts` 集成 `tailwind-merge` 进行样式管理。
