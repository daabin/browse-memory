- **统一消息总线**：定义 `RuntimeRequest/Response` 契约，由 `background/application.ts` 集中处理来自 UI（Dashboard/Sidepanel）和 Content Script 的所有业务请求。
- **事件驱动捕获**：Content Script 监听页面变更并通过 `chrome.runtime.sendMessage` 触发后台 `SessionCoordinator` 进行状态同步与数据持久化。
- **异步任务解耦**：引入 `TaskQueue` 与 `TaskRunner` 机制，将耗时的 Embedding 生成、内容摘要及报告撰写从主流程剥离，由 Service Worker 的 Alarm API 周期性驱动执行。
- **共享基础设施**：所有子模块共用基于 IndexedDB 的 `BrowseMemoryDatabase` 实例，并通过 `SecretStore` 统一管理外部 AI 服务的敏感凭证。
