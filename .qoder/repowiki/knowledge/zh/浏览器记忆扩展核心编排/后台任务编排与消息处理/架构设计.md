- **核心应用层**：`src/background/application.ts` 定义了 `BrowseMemoryApplication` 类，作为依赖注入容器和消息路由中心，聚合了数据库仓库、AI 客户端及安全模块。
- **消息处理边界**：`src/background/message-handler.ts` 提供统一的错误捕获与响应包装，将底层异常转换为标准的 `RuntimeResponse`。
- **会话协调器**：`src/background/session-coordinator.ts` 独立管理标签页的活跃状态与生命周期，通过适配器模式与持久化存储交互，并在会话结束时触发数据捕获。
- **异步任务子系统**：`src/queue/` 实现了基于数据库的生产者-消费者模型，`TaskQueue` 负责任务的入队、去重与状态流转，`TaskRunner` 负责批量拉取并执行注册的处理函数。
- **业务服务层**：`src/reports/report-service.ts` 封装了多语言报告的 AI 提示词构建与生成逻辑；`src/security/secret-store.ts` 利用 Web Crypto API (AES-GCM) 实现密钥的本地安全存取。
